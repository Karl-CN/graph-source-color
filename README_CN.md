# Graph Source Color

[English](README.md) | 中文

Obsidian 图谱节点动态着色插件。根据笔记关联的"源点"种类，在图谱视图中显示多色节点。

## 演示

[查看交互式演示](https://karl-cn.github.io/graph-source-color/demo.html) — 分步动画展示源点颜色如何沿链接传播。

## 功能特性

- **源点检测** — 自动识别指定文件夹下的源点笔记，每个文件夹对应一种颜色分组
- **关联传播** — 递归追踪出链和入链，通过 BFS 将源点颜色沿链接传播
- **多色渲染** — 关联多个源点的笔记显示分割色节点：
  - 2 个源点 → 左右分割
  - 3 个及以上 → 扇形分割
- **只读模式** — 不修改 Obsidian 原生 `graph.json` 配置文件
- **文件夹树选择器** — 设置页可视化选择源点文件夹
- **颜色继承** — 父文件夹颜色自动级联到未显式设色的子文件夹

## 安装

### 从 Obsidian 社区插件市场安装

1. 打开 设置 → 第三方插件
2. 搜索 "Graph Source Color"
3. 安装并启用

### 手动安装

1. 从 [最新 Release](https://github.com/Karl-CN/graph-source-color/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`
2. 将两个文件复制到 Vault 目录：`<vault>/.obsidian/plugins/graph-source-color/`
3. 重启 Obsidian，在 设置 → 第三方插件 中启用

## 配置

打开 设置 → "图谱源点着色设置" 进行配置：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 启用多色节点 | true | 为链接多个源点的笔记显示多色节点 |
| 源点文件夹 | — | 包含源点笔记的文件夹（每个文件夹 = 一个颜色分组） |
| 分组颜色 | 自动分配 | 每个源点文件夹对应的颜色 |

**提示：** 源点文件夹颜色也可以在 Obsidian 原生图谱设置中设置（使用 `path:` 查询的颜色组），插件会读取并遵循这些颜色。

## 工作原理

### 源点识别

放在配置的**源点文件夹**中的笔记自动成为源点笔记，所属文件夹即为分组。

### 关联逻辑

1. **出链方向** — 源点笔记链接到的笔记，自动关联该源点
2. **入链方向** — 非源点笔记链接到源点，自动关联该源点
3. **传播** — 已关联源点的笔记，通过其出链继续传播源点关系（BFS）

## 命令

| 命令 | 说明 |
